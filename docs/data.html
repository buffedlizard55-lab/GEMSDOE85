Data & sources

Every input byte is fetched from a commit-pinned mirror and verified against a SHA-256 before use. Nothing here is organizer-authenticated; the provenance column says exactly what each pin does and does not prove.

Access limitation, stated plainly. The competition data page (drivendata.org → Data) is behind a login, so this repository cannot fetch training_features.tif, labels.tif, sample_submission.tif or 1m_DEM_links.csv directly. It restores them from operator-supplied GitHub mirrors pinned by commit SHA and verifies every byte against the hash recorded in registry/data_manifest.json. That proves mirror consistency, not organizer authentication. Run python scripts/restore_data.py --groups core external scored to reproduce.
