H33 result: mechanism is plausible; causal explanation and score are unverified

The repository's byte-audit describes the H33 artifact as a sparse binary point set derived from a broader line-support surface, with a rule that removes predictions near mapped catalogue faults. A plausible explanation is metric alignment: distance-weighted credit saturates around covered truth, while additional unsupported mass increases the false-positive term. Sparsifying redundant nearby dots can therefore improve the precision/recall trade-off. This is a mechanistic explanation only; without the private evaluation labels, a submission-page receipt, and a matched ablation, this repository cannot prove that the pruning caused the reported score or predict a new score.

Score provenance: the value quoted for H33 in the standing prompt is not receipt-verified in this checkout.
