The competition in one paragraph (official source p967)

Task: Provide accurate information about presence of structures indicative of geothermal resources — namely geological faults — in the GeoDAWN region (NW Nevada, UTM 11N EPSG:32611, 100 m). Ground truth for currently known faults is public (USGS Quaternary fault database + INGENIOUS) but incomplete. Experts manually identified new faults not in USGS database; these comprise the private test set (initial prize round) and after expert review of all submissions the expanded label set (final prize round). Same submission scored twice: initial $50K (5×$10K) and final $250K ($100K/$70K/$40K/$25K/$15K). See competition structure and rules PDF.

  2. Go to Submit in sidebar → Make new submission.
  3. Under File to submit, click Choose file and select the downloaded gems85-h85-duplex-pullapart-worm-20261022T220544Z-2f8b57d9-zeros.tif (or a .zip containing it). Do not rename the inner GeoTIFF to a different CRS/shape.

    This is ≤140 chars, helps you tell submissions apart, and records HOLDOUT vs ORGANIZER-CONFIRMED labeling per protocol.
  5. Click Create. DrivenData will validate range [0,1], CRS, shape, transform. This file passes all 12 checks — you will not see "Predicted values must be in range [0, 1]". That error comes from sentinel -3.4e38 or NaN outside footprint — fixed here by writing 0.0 outside footprint with no nodata tag.
  6. Result appears on private leaderboard (score = DTI vs hidden truth, α0.2 β0.8 R=300 m). Your best submission counts toward standing; you may submit up to 3 per week — use them as an identification experiment (see below), not lottery tickets.
  7. Before deadline, select one submission to score across both rounds (initial + final after expert review). Same file scored twice.
