Method and limitations

Preregistered lane

Official feature band 19, det_elev_slope, is transformed with fixed Gaussian scales 0.5, 1, 2, and 3 pixels. The persistence envelope is emitted as separated local peaks away from the known catalogue.

Named non-fault mimics

Paleoshoreline benches, terraces, roads, mines, lithologic contacts, and processing seams can create the same slope edge. The holdout cannot prove discovery of private new faults.

Data access

The small grid/catalogue files and the feature stack are owner-supplied, hash-pinned mirrors. DrivenData authentication and private labels were unavailable to this run; the bytes are not organizer-authenticated.
