Top proposal: paired basin-interface flexure

It targets a buried structural juxtaposition rather than another topographic scarp. The central falsifier is whether matched, non-tectonic facies/basement transitions produce the same signed profile. Before any holdout comparison, each input feature would need its own leakage canary; catalogue-derived features, if any, must be recomputed from fold-visible faults only. Evaluation must use whole-component buffered splits, exact masking of visible faults, pooled DTI, and paired spatial-cluster uncertainty.
