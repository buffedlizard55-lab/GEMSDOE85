How to make a competition submission

Current decision: do not submit.

No new submission TIFF, candidate name, or candidate SHA-256 exists. No scientific improvement or uniqueness clearance is claimed. Download the negative run card.

Why there is no download button for a TIFF

The literal registry overlap policy excludes every nonempty candidate because a prior has positive support across the whole footprint. An explicit method lane and the exact transformed cache are also missing. Publishing an old or arbitrary raster would not solve these failures.

This project automates its current checks; it does not require a human to visually inspect a TIFF. Resolving a missing assignment or contradictory policy is not an image-inspection task. The separate organizer expert review is part of the official competition structure and cannot be replaced by this project.

Required path before a file is offered

  1. Resolve the literal overlap policy and supply the explicit parallel-run lane; restore the exact cached feature stack with provenance.
  2. Implement only that lane. Withhold whole fault components with a buffer. Compute catalogue features from fold-visible faults only; mask non-withheld mapped faults exactly.
  3. Test every feature alone as a leakage canary. Stop for suspicious AUC until investigated. Evaluate candidate and current incumbent on the same spatial holdout with the shared pooled DTI evaluator and paired confidence intervals.
  4. Beat the comparable incumbent before asking a separate selector to consider a slot. A holdout gain is not a guaranteed public/private gain.
  5. Check rank correlation on the surface before placement and literal dot-overlap/correlation again after placement against the complete accessible registry. Stop and log duplicates.
  6. Package via the unmodified shared writer. Reopen the exact TIFF bytes, verify the grid/range/footprint and one-TIFF ZIP, and publish the SHA-256 plus a unique name and a note of at most 140 characters.
  7. Only the separate selector may approve a weekly slot after checking the account-specific quota on the authenticated organizer submission page.

File format checklist

The official format specification calls for a single float32 layer with confidence values in [0,1], matching the reference CRS, shape, bounds and geotransform. The mirror reference is EPSG:32611 at 100 m resolution, with height 3730 and width 3292. These are format constants, not scores.

The template uses the conservative all-finite, no-nodata, zero-outside policy. The public spec permits null/NaN outside bounds; we cannot infer the cause of the previous range error from its wording alone. Reject out-of-range model output rather than silently clipping it. Local format PASS is not organizer acceptance.
