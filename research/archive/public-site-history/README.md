# Archived public-site research pages

These files were previously served beneath `docs/research/`. They are retained for historical audit only. They include prior-session score labels, experiments, source-access statements, and candidate claims that are not revalidated current status and may conflict with the present fail-closed review.

The current public site is generated by `scripts/build_site.py`; the current decisions are in the root `README.md`, `research/review.md`, `evidence/run_card.json`, `registry/lane.json`, and `registry/submission.json`. Do not use these archived pages to select a lane or download/submit a historical raster.
